# 18 - Detection Engineering with Sigma Rules

This directory contains comprehensive detection engineering methodologies using Sigma rules. Sigma is a generic and open signature format that allows you to describe relevant log events in a straightforward manner. These modules guide you through Sigma fundamentals, rule creation, conversion, and deployment in Microsoft Sentinel.
